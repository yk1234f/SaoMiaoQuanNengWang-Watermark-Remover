# PDF 固定水印清理

双击 `PDF水印清理.exe`，把一个或多个 PDF 拖进窗口，自动开始处理。也可以点击“选择 PDF”，或拖入文件夹（仅处理第一层 PDF）。

默认输出到原文件旁的“去水印输出”文件夹。可在添加文件前设置统一输出位置。原文件始终保留；同名输出自动加序号。文件按队列逐个处理，单个失败不影响后续文件。处理时请保持窗口打开。

本版本针对《2025 计算机真题.pdf》右下角“扫描全能王”独立图片水印，使用图片内容的 SHA-256 精确匹配。相同模板可批量处理；未匹配会跳过，不生成副本。仅处理页面直接引用的该水印，不自动删除其他图片、二维码或正文。不支持已与扫描正文合并的水印，也不保证匹配其他版本的同品牌标识。

直接修改 PDF 的图片绘制指令，不重新扫描、涂白、OCR 或压缩正文。保留页数、页面尺寸及原扫描图像数据。所有处理都在本机进行，无上传。

源码：`app.py` 是窗口，`cleaner.py` 是清理逻辑。开发环境需要 Python、pypdf、tkinterdnd2；打包需要 PyInstaller。

命令行用法：

```
python cleaner.py "输入.pdf" --output-dir "输出文件夹"
```
